# Checklist

- [x] 后端 FastAPI 服务可启动，`dwg2dxf` 可执行文件缺失或转换失败时有明确错误返回
- [x] `POST /api/dwg/upload` 接受 .dwg 文件，返回 fileId 及图纸清单（id、name、width、height）
- [x] 非 DWG 文件、损坏 DWG 上传时返回友好错误，前端有对应提示，页面不崩溃
- [x] 图框检测对标准 A0–A4 图幅（横/竖、±2%、等比缩放）识别正确，多图框数量与实际一致
- [x] 块参照形式的图框可通过块名或包围盒识别
- [x] 图名按「块属性 → 标题栏最大文字 → 图纸N」优先级生成，重名自动追加序号
- [x] 未检测到图框时回退生成 1 张「全图」
- [x] 每张图纸输出独立 DXF，内容限定在对应图框范围内，图层/颜色/线型/块视觉与原图一致
- [x] `GET /api/dwg/{fileId}/sheets/{sheetId}` 可正确下载图纸 DXF，重复请求结果一致
- [x] 前端支持点击与拖拽上传 DWG，并展示上传/解析状态
- [x] 侧栏列出全部图纸，点击后不刷新页面即可切换显示并自适应铺满
- [x] 视口支持鼠标缩放、平移
- [x] 图层面板可切换图层显隐且即时生效
- [x] 使用 `earthwork/` 示例 DWG 的端到端流程全部通过
- [x] 临时文件按 fileId 隔离并具备过期清理能力
